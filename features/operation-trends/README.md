# 稼働貢献ニュース・設定投入傾向 MVP

独立ページ: `features/operation-trends/index.html`。既存の機種情報・期待値エンジン・ルートページは変更しない。

## 使用方法
ブラウザで HTML を開き、ニュースを手動登録するか、公開データのCSVを読み込む。端末内 localStorage に保存。ニュースと集計結果は JSON でエクスポート可能。自動クロール・外部送信なし。

CSV列: `store,machine,date,net_coins,games,first_hits,confirmed_setting,source_url,rights_verified`。必須は先頭5列。date は YYYY-MM-DD、rights_verified は `true` のみ確認済みとして集計。

## データの解釈と制限
- ニュースの「継続」「終了」は入力された情報源に基づく記録で、未確認の断定は禁止。確認日と出典URLを必須とする。
- 店舗・機種・曜日の差枚/G数/初当たりは実測の集計であり、高設定投入の確率・設定推測・期待値ではない。
- confirmed_setting は確定演出等の根拠が別途確認された場合にのみ入力する。現状は確定根拠URLを行単位で厳密に検証していないため、集計表示は参考扱い。
- 信頼度は標本件数・異なる日数・利用条件確認フラグによる「集計資料としての参考度」。統計的有意性や高設定投入の信頼度ではない。
- CSVはインポート時に以前の観測データを置換。ブラウザ間の同期なし。出典の利用規約確認・引用範囲判断は利用者が行う。
- 将来連携用JSONには schema_version を付与。機種ID、店舗ID、データの取得時刻、確定根拠、データライセンスの正規化は今後追加する。
