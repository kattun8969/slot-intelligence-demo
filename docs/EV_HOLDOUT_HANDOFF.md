# 独自期待値：時系列ホールドアウト検証 v0.1

## 変更ファイル
- `scripts/ev_holdout_validation.py`：実戦の時系列分割・前後期間比較
- `tests/test_ev_holdout_validation.py`：架空実戦による検証
- `docs/EV_HOLDOUT_HANDOFF.md`：本書

## 目的
同じデータで「狙い目の条件を探す」と「精度を検証する」を同時に行うと、偶然当たった条件を優秀と誤認する危険がある。そのため、日付を指定して、**境界日より前を学習、境界日以降を検証**として厳密に分離する。

## 入力
独立した完結実戦の機種ID・型式・カウンター種類/起点/開始値・状態・交換率・やめどき・店舗ID・日付・実投資/回収額・許諾情報。

## 出力
条件ごとに学習件数・検証件数・店舗数・平均純収支・平均差・検証標準誤差・最低件数充足を返す。初期の最低件数は各30件だが、**30件で信頼できると断定する基準ではない**。データが少ない場合は `insufficient_samples` とする。

## 限界
時系列検証でも設定配分、着席の選択バイアス、同一台の相関、未完結プレイ、閉店打ち切り、実戦記録の偏りは除去できない。検証データを見てから開始G数や分割日を都合よく調整しない。今後は店舗単位の外部検証とクラスタ相関を考慮する。
