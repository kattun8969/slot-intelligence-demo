# 独自期待値エンジン：共通データ契約 v0.1

## 開発担当・隔離範囲
このPRは **独自期待値の研究基盤だけ**。機種ページ、狙い目、機種画像、公開期待値データ、サイト表示には変更を加えない。mainの確認済み基点：`b634252f1ecf17d326990f8481d1817ef83dbda0`。

## 入力契約（1プレイ＝1行）
`scripts/ev_engine_core.py` の `validate_episode(row)` が入力を検証する。

| キー | 内容 |
|---|---|
| episode_id / venue_id / date | 同一店舗・同一日内の一意な実戦識別子 |
| machine_id / model_revision | 機種と型式。型式をまたいで混合しない |
| counter_type / counter_value | AT間G、CZ間G、周期数、周期内G、液晶pt、当日差枚、有利区間差枚のいずれか |
| state / state_evidence | 状態ラベルと「実測・公開解析・推定・シミュレーション」の種別 |
| investment_yen / return_yen | **当該実戦の実際の投入・回収額**。店舗の当日差枚から推測しない |
| exchange_basis | 換金率・貸出条件を同一文字列で記録。違えば別グループ |
| play_end_condition / completed | 終了条件と実戦の完結確認。途中終了・未追跡は集計対象外 |
| source_permission | 許諾CSV、手動公開記録、公式API、自己所有データのみ |

「駆け抜け確定」「設定変更確定」などは根拠を確認できる実測以外から推測しない。店舗の「BB」「当り」だけでAT当選と断定しない。

## 出力
`summarize_episodes(rows, min_samples=30)` は **完全な実戦単位** でグループ別の平均純収支、標準誤差、正規近似95%区間、件数、最低件数を満たすかを返す。

**重要：** 最低件数を満たしても `publication_status=research_only`。観測サンプルの平均は、ホールで未着席の台から打ち始める戦略の期待値とは限らない。着席選択、閉店打切り、AT/CZカウンター定義、設定配分、未完結データの偏り、実戦結果の重複を別途検証する必要がある。95%区間も独立・同分布を仮定した暫定指標で、精度保証ではない。
