# 生活再建支援・広告導線の非公開試験素材（2026-11-27）
このフォルダは **WordPressへ自動反映しないGitHub作業ブランチ専用** です。旧GitHub Pagesへ変更、マージ、デプロイしないでください。

- `preview.html`：320px/375px・PCで確認する**非クリック可能な静的モック**。実広告タグ、紹介リンク、アカウント識別子は含みません。
- 案A：生活再建の一般情報・公的相談先へ導く中立的な案内。
- 案B：専門家相談広告を想定したPR表示付き枠。案件の広告主・正式なASPコード・契約上の表示許可・独自バナー使用許諾の照合が済むまで公開不可。
- 案C：カード新規発行広告ではなく、リボ/分割手数料と利用明細の確認を促す案内。**返済困難な読者に追加の信用枠や借入を勧めない**。

## クレジットカード案件の検討方針
1. 「リボ・手数料が高い」「毎月返済が苦しい」読者には新規カードやキャッシングの広告を出さず、明細・支払方法・公的相談先の確認を案内。
2. 安定した支払余力があり、毎月全額支払える人だけを想定する独立記事では、年会費・手数料・ポイント還元・審査要件・支払条件を比較できる。実案件の報酬/掲載許可は未確認。
3. クリック数/資料閲覧数を集計する際に個人の借入状態や延滞、遊技状況を識別・推定してターゲティングしない。
4. 広告導線の追加判断は③、WordPress実装/公開は②、ASP管理画面と広告規約の照合・成果の評価は④。
5. 「PR」や `rel="sponsored"` を表示要件に含め、ASPの発行タグを勝手に書き換えない。行政の公的ページを広告と混同させない。

## ロールバック
