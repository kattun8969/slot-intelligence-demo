- **正式A8コード／トラッキング識別子はPublic GitHubには保存しない**。ユーザーから共有された汎用テキスト広告リンクは担当②に非公開で渡す。

- ③の確認なしにWordPress公開しない。旧GitHub Pagesへマージ/変更/デプロイしない。WP本番は②編集者のみが編集。
- 収益計測：記事URLごとの広告枠表示/クリック、ASP発生成果/承認成果/確定報酬、手数料・作業コストを区別。確認できない数値は0や推定値で埋めない。
