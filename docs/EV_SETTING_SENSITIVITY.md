# 設定別実測収支と設定配分シナリオの感度分析

`scripts.ev_setting_sensitivity.analyze_setting_sensitivity(rows, scenarios, min_per_setting=10)` は、設定1〜6が個々の実戦で確認されている完了済みエピソードだけを対象とする。

機種・型式・カウンター起点・開始値・終了条件・交換条件が混在している入力は拒否する。各設定の実測平均収支・標準誤差・件数を出し、指定した仮の設定比率による加重平均を計算する。対象設定の実測がない、または最低件数未満の場合は**推測補完せず計算不可**とする。

```python
analyze_setting_sensitivity(rows, {
    "低設定多め（仮定）": {"1": 0.8, "6": 0.2},
    "均等（仮定）": {"1": 0.5, "6": 0.5},
})
```

この例の配分は計算方法の説明用であり、実店舗の配分や機種の実測数値を示すものではない。**シナリオ加重平均は、設定配分の仮定を変えた場合の感度を示すだけで、実店舗の攻略期待値ではない。** 収集バイアス、未確認設定、サンプル不足、選択条件の偏りを補正するものではない。常に研究用として扱う。
