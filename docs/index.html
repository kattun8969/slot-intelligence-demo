このデモでできること

1. 重点機種を選ぶ

優先14機種から選択。名称が未確定の候補も区別。

2. 現地の事実を記録

機種別の項目を表示。未確認でもメモを保存できます。

3. 確認漏れを見つける

条件の矛盾を確認。不明な項目は入力不要です。

仮公開デモ：機種名と入力項目の操作を試すためのものです。天井・期待値・設定推測・「打てる／打てない」は未提供です。登録データが足りない機種について判断を作りません。メーカー・解析サイトの正式な確認を経た運用版とは異なります。

狙い目を一覧から探す

現在の機種が候補に合わなかったら、別の機種を一覧から選び、確認すべき条件や出典を見比べられます。打った台の期待値の記録・累計もこちらから確認できます。

狙い目候補一覧を見る期待値の記録を見る

試用版のため、実際の天井・ゾーンの具体的な狙い目や計算済み期待値は未掲載です。

本公開までに追加するもの

実機解析の条件付き照合機種別の入力項目出典と更新履歴調査候補の承認

確認済みの解析数値が揃うまで、天井からの残りゲーム数、勝率、期待値などは表示しません。新しい解析で条件が変更された場合は、出典を比較し、差分を確認してから反映する予定です。
