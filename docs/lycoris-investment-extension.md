# リコリコ ATまでの投資・所要時間（差分アドオン）
**状態：②編集者レビュー待ち／本番未実装／値の根拠がない限り数字を表示しない。**

## 目的
既存のリコリコ期待値チェック `#ly-calculator` に「平均投入相当額・枚数・時間」と「AT到達までの80%分位点の投入相当額・枚数・時間」を追加する。現行期待値・PAPIMO・投票・記事は削除・上書きしない。対象は `#ly-scenario` の0〜2（ATまで）だけ。3（CZまで）・4（ゾーンまで）は対象外。

## 現状の未確定データ
現行の開始G別期待値の「収支（円）」は、AT到達までの残りゲーム数の分布とは異なる。**期待収支や天井から平均投資・80%予算を逆算しない。** 現在は公開可能な条件別AT到達分布が未検証なので `MINNA_LY_INVESTMENT_MODELS` は未設定のままが正しい。既存の「想定する現金投資（円）」は手動の換算入力であり、自動推定投資額とは異なる。

## データ契約
編集者がモデルを検証できた後、アドオン読み込み**前**に次のようなスキーマの `window.MINNA_LY_INVESTMENT_MODELS` を登録する。以下は形式の例であり、**数値はダミーのため本番登録・公開禁止**。

```js
// 本番には実際の根拠付きデータのみを登録する。
// window.MINNA_LY_INVESTMENT_MODELS = {
//   '0': {
//     sourceUrl: 'https://EXAMPLE.invalid/source',
//     checkedOn: 'YYYY-MM-DD',
//     endpoint: 'first AT', counter: 'data-counter G',
//     startingState: 'lower AT ended',
//     method: 'measured',             // or 'estimated'
//     coinBasePer50: 0,              // 検証済み50枚あたり回転G
//     spinsPerHour: 0,               // 実消化G/時間
//     byCurrentG: {
//       '300': [[0,0]]               // [残りG,確率]、実測分布のみ。合計1。
//     }
//   }
// };
```

**必須根拠：** 機種・状態（下位AT後／駆け抜け後／リセット）・カウンター起点・途中のCZ/ボーナス/ST処理・設定構成・対象サンプル数・集計日・コイン持ち・実消化速度・終了地点。分布外の現在Gに根拠のない補間を行わない。

計算：平均残G = Σ(残G×確率)、80%点 = 累積確率≥0.8になる最初の残G、投入枚数 = 残G×50÷50枚あたり回転G、円換算 = 投入枚数×1000÷1000円の貸出枚数、時間（分） = 残G×60÷1時間の消化G数。

80%金額は「当選までの**投入相当額**」の分位点を単純回転数から換算した指標であり、途中払出・持ちメダル・再プレイ等を含む**現金を準備すべき確定額ではない**。利益率・勝率・損失確率でもない。必ず説明を表示。
