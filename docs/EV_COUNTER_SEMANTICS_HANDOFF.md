# カウンター値の意味・符号・起点の管理

## 実装
`scripts/ev_counter_semantics.py` では、AT間・CZ間・周期・ポイントなどの**非負整数カウンター**と、日別・区間差枚の**符号付き整数カウンター**を明確に分離する。

- `at_games`, `cz_games`, `bonus_games`, `cycle_number`, `cycle_games`, `screen_points`: 0以上のみ
- `daily_difference_medals`, `section_difference_medals`: マイナス値を許可
- 値が減少したことだけをリセット・AT終了・有利区間切断の根拠としない
- 起点が異なるカウンター同士を連続した履歴として比較しない
- 境界イベントの根拠が存在しても、元データの確認が必要

## 未統合部分
PR #45のCSV取込、PR #33の正規化、PR #34の監査では、現状マイナス値を一律拒否するため、本モジュールだけ追加しても**負の差枚は取り込めない**。これらを統合する際、`counter_label`を確認済みルールで`counter_type`に変換した**後**に符号の妥当性を検証する必要がある。未確認のラベルを負数から差枚と推測してはならない。

また、`ev_engine_core.py`の投資・回収額は非負であり、差枚のマイナス値をそのまま金額欄へ流用しない。

## テスト・影響
架空値による12ケース。既存の機種ページ・表示・実測EVには変更なし。公開前に独立した統合テストで差枚負数の取り込み経路を検証する。
