    報酬レベル狙い｜連続回数と到達経路を合わせて判断

    BIG2連・3連・4連・5連以上を固定の開始基準にはしません。ボーナスの並び、通常時の消化G数、レア役、示唆から現在の報酬レベルを考えます。エピボ間のハマりだけでは、打てる根拠になりません。

    レベルが落ちる区切り・引き継ぐ経路
    • 通常時の初当たりでエピソードが選ばれた場合：ファンレター・SAO失敗者・イカれたレンは転落の区切りです。
    • SJ1を経由したSAO失敗者：メーカーは報酬レベルが転落しないと説明しています。
    • BIG・REG中のレア役で報酬を昇格させ、SAO失敗者を獲得：通常時の初当たりで直接選ばれたケースとは分けて記録します。この経路を直接名指しした転落・引き継ぎ条件は今回確認できていないため、どちらとも断定しません。
    • 有利区間終了：転落の区切りです。エピボ未当選でも、それ以前のG数を現在レベルの蓄積として数え続けないよう注意します。

    ボーナス名だけでなく「どの場面の抽選で獲得したか」が重要です。

    メーカーの転落条件・SJ1経由の説明
    筆者実戦：エピボ未当選が長く続いた例

    ボーナス中のレア役による昇格でSAO失敗者を獲得。その後約2,000G、リセットから累計約6,000Gを消化してもエピボに当選せず、REG比率も高かったとの報告です。

    筆者実戦・1事例／2026年11月16日受領。実戦日、通常時とST等のG数内訳、BIG・REGの各回数、有利区間終了の有無は未記録。REG比率の数値は算出していません。

    編集部考察：長いエピボ未当選は、高レベル到達の証明にはなりません。低レベルに残っていた可能性や、途中で有利区間が終了した可能性もあります。この1事例から「ボーナス中の昇格で転落する」とも断定できません。

    BIG2連・3連・4連・5連をどう評価するか

    各連続回数について、レベル別滞在確率と次回の期待収支を分けて推定する方針です。現時点では初期レベル分布・昇格率・レベル別BIG/REG振り分けが不足しており、確率の数値は掲載していません。

    BIGが続けば高レベル期待度が上がる可能性がある一方、エピボが選ばれていない履歴も反映する必要があります。推定した期待度が下がることと、実際の内部レベルの転落は別です。

    レア役を引いた回数も、昇格に成功した回数とは限りません。現在G数だけでなく、最後の転落契機からの通常時G数と示唆を確認してください。

    ホールでの確認順・やめ時
    1. ぱちログでBIG・REG・通常時エピソードの順番を確認する。
    2. SAO失敗者は初当たり・ボーナス中昇格・SJ1経由を区別する。
    3. 有利区間終了の有無、報酬レベル示唆、現在G数、スルー回数を確認する。
    4. 報酬レベルだけで追わず、別途掲載しているゲーム数・天井条件と照合する。

    エピボ間G数やBIG連続回数だけでは続行を決めません。初当たり後は付随するCZ・ST等を確認し、終了時の状態から再判断します。転落の区切りが来ても、前兆・CZ・STを残した即やめを勧めるものではありません。
