# 負の差枚：CSV → 正規化 → 監査の統合検証

## 実装方針
1. CSV段階は値の符号を**仮受理**し、日付・出典・権限申告・重複などを検査する。CSVの取り込み成功だけでは意味の確認済みを示さない。
2. 正規化でデータ提供元・店舗・機種・型式・日付・カウンターラベル・イベントラベルを照合し、**確認済みルールが一意**の場合だけ符号を確定する。
3. 負数を許すのは `daily_difference_medals` と `section_difference_medals` のみ。未確認・複数一致・G数負数は隔離する。
4. 監査では、差枚の減少をリセットの根拠にしない。AT間・CZ間などの減少は引き続き要確認とする。
5. 店舗観測履歴から期待値・実収支を生成しない。
