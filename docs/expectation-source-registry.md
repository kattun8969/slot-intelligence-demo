# 期待値・解析資料台帳（非公開原本の参照管理）

更新日：2026-11-22。機種資料を見つけるための索引。**原本・購入資料・第三者サイトを保存したHTML/ZIPをPublic GitHubへアップロードしない。** 台帳は原本そのものや著作物の転載許可を意味しない。

## 保管先と責任分担
- **Google Drive（予定／未接続）**：機種別の非公開原本。Google Driveへの過去資料のコピーは**未実施**。
- **ChatGPTファイルライブラリ（現状）**：過去のチャットでアップロードされた原本が確認できる場所。チャット内の添付ファイルと混同しない。
- **ChatGPTプロジェクトのソース**：主要な完成見本・よく参照する資料に限定。
- **GitHub（本台帳）**：機種ID、非公開原本の場所（アクセス権管理済みリンク）、版、条件、処理状況、対応Issue。外部への閲覧権限を与えないURLでも、リンク自体を公開してよいかを確認してから記載。
- **②Work**：①提出の公開可能な独自編集データ・コードをWordPressへ反映し、本番検証。元データがあるだけでは公開済みとしない。

## Driveフォルダ案（まだ作成していない）
```
みんなの期待値｜資料保管庫/
  00_制作基準・完成見本/
  01_期待値資料_非公開原本/
    <機種ID>/
      original/
      versions/
  02_機種別解析資料/
  03_PAPIMO・実戦データ/
  04_画像・示唆資料/
  05_過去資料・更新履歴/
```
原本フォルダは非公開・最小権限で運用する。収集元、保存日、条件（AT/CZ/ボーナス/スルー/周期/交換率/閉店考慮）、版、最終確認日を付ける。HTMLとZIPは同一保存版をペアで管理。異なる版は上書きせず履歴を残す。

## 登録・編集の流れ
1. Google Drive接続後、フォルダ作成。既存ライブラリから資料を**同一性確認後**に移す（Driveリンクが未取得の間、URLを推測しない）。
2. 原本の機種名・保存時期・著作物の取り扱いを確認。重複版は `versions/` に隔離し、最新版を機械的に決めず比較。
3. ①が原本を参照して**公開可能な独自編集表**を作る。原本の表画像や購入ページの実質複製をPublic GitHubやWordPressへ公開しない。
4. 対応Issueで「原本ID、出典、適用条件、下書きコード、未確認事項、次担当」を記載し、②が一括公開する。
5. Driveアップロードが完了した機種のみ「未移行」を変更。名前の存在だけで本文検証済み扱いしない。
