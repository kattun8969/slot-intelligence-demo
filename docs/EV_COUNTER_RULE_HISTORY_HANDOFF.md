# カウンタールールの履歴・出典固定

データ提供元・店舗・機種・型式・カウンター名・イベント名をキーに、ルールを適用開始日・終了日付きで保存する。ルールの意味が変わった場合、既存レコードを暗黙に最新ルールへ再解釈しない。

- `review_registry`: 同じキーに対する**確認済み**ルールの適用期間重複を検出する。境界日は両端を含むため、6/30終了と7/1開始は非重複。
- `pin_observation`: 観測レコードの正規化結果が、明示されたルールID・バージョン・適用日・定義に一致することを検証し、SHA-256ハッシュと根拠URLを記録する。
- `verify_pinned_snapshot`: 後から参照したルールの内容が当時固定したスナップショットと一致するかを確認する。
- 未確認ルール、重複、矛盾、適用期間外は安全側で停止する。

**制約**: ハッシュは内容の変化検出であり、出典が真実であることや利用許諾を証明するものではない。観測データの取り込み・期待値計算・公開サイト更新はしない。現在のPR #33と統合する際は正規化直後にピン留めし、ルール変更履歴を保持する。機種の正式ルールは未登録。
