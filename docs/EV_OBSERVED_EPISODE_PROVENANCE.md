# 実測エピソードの厳格な収支集計

`scripts.ev_observed_episode_provenance` は、従来の探索用 `summarize_episodes` と別の厳格な研究用経路です。

## 必須条件

- 開始条件、実際の投資額・回収額、終了条件が揃った完了済み実戦エピソード
- `state_evidence=observed`（推定・シミュレーションは実測に混ぜない）
- **エピソードごとの** `counter_origin`、確認済みのルール版とSHA-256、適用期間内の日付
- 提供元・店舗・機種・型式と、HTTPSのデータ出典・利用権限・起点定義の根拠
- 公開ホールの差枚グラフだけでプレイヤーの投資・回収額を捏造しない

集計キーにカウンター起点を追加し、同じ300GでもAT間とCZ間を混在させません。サンプル数、平均収支、標準誤差、95%参考区間を出しますが、**選択バイアスや設定配分を補正した攻略期待値ではありません**。常に `publication_status=research_only` です。

この変更では実際の店舗データは取得せず、機種ページの期待値・狙い目も変更しません。
